# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works
with multi-package repos, or single-package repos to help you version and publish your code. You can
find the full documentation for it [in the changesets repo](https://github.com/changesets/changesets).

## Adding a changeset

Run `npx changeset` to create a new changeset describing your change.

Each changeset is a markdown file in this directory with YAML front matter declaring which
package is affected and the semver bump type. The body describes the change for the CHANGELOG.

## Semver policy

- **patch** — bugfix or regenerated output with no visual change
- **minor** — new fonts, tokens, themes, patterns, or plates
- **major** — removed or renamed tokens, dropped font families, breaking LESS variable changes, manifest schema change
