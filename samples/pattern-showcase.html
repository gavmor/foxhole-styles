NOTE — CORRECTION PATCH: The .notebox class now carries the correction-patch styling as its only form: a dirty-white tape slip, rotated -0.7deg, with a faint paper-on-paper shadow. The previous bordered variant is retired because the correction patch is the defining voice for diegetic annotations — not a style choice. Downstream consumers that want a bordered callout should define their own class instead of overloading .notebox.
